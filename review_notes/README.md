# Review notes

How reviewers decided cases that the card alone does not settle. Each note is
one case and applies to every pair on the dandisets it lists, in any round.

A note starts with the dandisets it applies to, written as a JSON list:

```markdown
---
dandisets: ["000128", "000138", "000139", "000140"]
---

# MC_Maze

...
```

A review call is filed under a paper DOI and a dandiset, so the notes behind a
call are the ones whose `dandisets` include that dandiset.
